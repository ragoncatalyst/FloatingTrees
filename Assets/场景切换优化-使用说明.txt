========================================
场景切换优化 - 使用说明
========================================

【已完成的优化】

1. ✅ 异步场景加载
   - 使用 LoadSceneAsync 代替同步加载
   - 避免主线程阻塞，提升响应速度

2. ✅ 淡入淡出过渡效果
   - 添加 0.3 秒的黑屏淡入淡出
   - 让切换更加流畅自然

3. ✅ 分帧处理方块状态
   - 使用协程每处理一层方块就 yield 一次
   - 将 125 个方块的处理分散到 5 帧
   - 避免单帧处理过多造成卡顿

【需要手动设置】

请在 Unity 编辑器中完成以下步骤：

步骤1：创建 SceneTransitionManager 对象
--------------------
1. 在 Hierarchy 中右键 → Create Empty
2. 重命名为 "SceneTransitionManager"
3. 添加组件：Assets/Scripts/SceneTransitionManager.cs
4. 设置为 DontDestroyOnLoad（脚本会自动处理）

步骤2：可选调整
--------------------
在 SceneTransitionManager 的 Inspector 中可以调整：
- Fade Duration（淡入淡出时长）：默认 0.3 秒，可根据喜好调整

【预期效果】

优化前：
- 同步加载，卡顿 3 秒
- 突然黑屏切换，体验不佳

优化后：
- 异步加载，不阻塞主线程
- 平滑淡入淡出效果
- 分帧处理，避免卡顿
- 预计切换时间减少到 0.5-1 秒

【技术细节】

1. 场景切换流程：
   按下 Enter → 保存状态 → 淡出(0.3s) → 异步加载场景 → 淡入(0.3s) → 分帧应用状态(5帧)

2. 性能提升：
   - 异步加载：不阻塞主线程，可以显示进度
   - 分帧处理：每层 25 个方块，分 5 帧处理，每帧只处理 25 个
   - 视觉优化：淡入淡出效果掩盖加载时间

3. 如需进一步优化：
   - 可以在 SceneTransitionManager 中添加加载进度条
   - 可以添加 "Loading..." 文字提示
   - 可以预加载常用资源

【故障排除】

如果切换仍然卡顿：
1. 检查是否创建了 SceneTransitionManager 对象
2. 检查 Console 是否有错误信息
3. 确认场景中没有其他脚本在 OnSceneLoaded 时执行大量操作

如果出现黑屏问题：
1. 检查 SceneTransitionManager 的 Canvas 设置
2. 确认 Canvas 的 Render Mode 是 Screen Space - Overlay
3. 检查 Sorting Order 是否为 9999（最顶层）
